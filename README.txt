CLEAN HUD - one-key / one-button HUD toggle for Red Dead Redemption 2

REQUIREMENTS
- ScriptHookRDR2 + an ASI loader

INSTALL
1. Copy CleanHUD.asi and CleanHUD.ini into your RDR2 game folder (next to RDR2.exe).
2. Start the game.

DEFAULT CONTROLS
- Keyboard:   F11
- Controller: LB + D-Pad Down  (Xbox pads; PlayStation pads via Steam Input / DS4Windows)
Everything is configurable in CleanHUD.ini ([Keys] and [Controller] sections).

UNINSTALL
Delete CleanHUD.asi, CleanHUD.ini and CleanHUD.log.

SOURCE
Full source code: [GitHub link]
This plugin only reads input and calls in-game HUD functions. It does not use the
network and only reads/writes its own .ini and .log files.
